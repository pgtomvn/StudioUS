# Tài liệu tham khảo

Hai PDF đề bài được giữ nguyên tại thư mục gốc. Danh mục nguồn và trạng thái xác minh nằm trong `docs/data-sources.md`.

Chỉ thêm bản CTĐT, quy định hoặc tài liệu tham khảo đã ghi rõ nguồn, ngày truy cập và phạm vi sử dụng. Bản `softwareEngineering_information.pdf` đã được bổ sung tại thư mục gốc; mới nhận diện trang đầu, chưa đọc toàn văn hoặc đối chiếu quy tắc. Hai file mẫu UI/UX và LaTeX cũng được giữ nguyên tại thư mục gốc, chờ đọc khi làm phần tương ứng.
